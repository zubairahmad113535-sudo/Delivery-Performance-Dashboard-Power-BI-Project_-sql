# 🚚 Delivery Performance Analysis | SQL & Power BI

## 📌 Project Overview

This project focuses on analyzing delivery operations to understand delivery performance, identify delays, and explore factors that may affect delivery efficiency.

Using SQL for data preparation and querying, and Power BI for interactive visualization, this project transforms raw delivery data into meaningful information that can help businesses monitor operations and make data-driven decisions.

## 🎯 Business Objectives

- Monitor overall delivery performance.
- Analyze delayed and on-time deliveries.
- Compare actual delivery times with expected delivery times.
- Evaluate delivery performance across regions and delivery partners.
- Understand how weather conditions, vehicle types, and delivery modes relate to delivery outcomes.
- Analyze delivery distance, package weight, and delivery costs.
- Identify opportunities to improve operational efficiency and customer satisfaction.

## 🗂️ Dataset Description

The dataset contains delivery-related information, including:

| Column | Description |
|---|---|
| Delivery_Date | Date of the delivery |
| Delivery_ID | Unique delivery identifier |
| Delivery_Partner | Partner responsible for delivery |
| Package_Type | Type of package |
| Vehicle_Type | Vehicle used for delivery |
| Delivery_Mode | Mode of delivery |
| Region | Delivery region |
| Weather_Condition | Weather during delivery |
| Distance_KM | Delivery distance in kilometers |
| Package_Weight_KG | Package weight in kilograms |
| Delivery_Time | Actual delivery time |
| Expected_Time | Expected delivery time |
| Delayed | Indicates whether delivery was delayed |
| Delivery_Status | Final delivery status |
| Delivery_Rating | Customer delivery rating |
| Delivery_Cost | Cost associated with delivery |

## 🛠️ Tools & Technologies

- **MySQL:** Data exploration, querying, filtering, sorting, and aggregation.
- **Microsoft Power BI:** Dashboard creation, KPI cards, interactive visuals, and performance analysis.

## 🔍 Key Business Questions

1. What is the overall delivery performance?
2. How many deliveries are delayed compared with on-time deliveries?

4. Which delivery partners perform better?
5. How do weather conditions relate to delivery delays?
6. How do vehicle types and delivery modes compare?
7. How do distance and package weight relate to delivery time and cost?

This project demonstrates how SQL and Power BI can be used together to analyze operational data and communicate performance through an interactive dashboard.

The analysis can help decision-makers monitor delivery operations, investigate potential causes of delays, compare regional and partner performance, and identify opportunities to improve efficiency and customer experience.
